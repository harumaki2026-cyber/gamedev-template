# 要件定義書


## 1. どんなゲームか？


「敵を倒しながら進み、4つのフェーズを突破し侵略するシューティングゲーム」


操作：矢印キーで上下左右に動き、スペースキーで弾を発射


## 2. 勝ち条件 / 負け条件


- 勝ち：最後に出てくる大ボスのHPを0にするとクリア
- 負け：敵や敵の撃つ弾に当たり、HPが0になるとゲームオーバー


## 3. 作らないもの


- BGMと効果音なし
- ステージは1面のみ
- セーブやランキングなし


## 4. これができたら完成


1. プレイヤーは矢印キーで上下左右に動かせ、スペースキーで弾を発射できる
2. 敵にプレイヤーの出した弾を当てると敵のHPが減り、0になると消滅
3. 大ボスのHPを0にするとクリア
4. 敵本体や敵の撃つ弾に当たるとプレイヤーのHPが減り、0になるとゲームオーバー


## 5.その他仕様


- ゲーム内の時間単位として60fを1秒として扱う
- 実際のフレームレートが変動しても、経過時間に応じて処理する
- 当たり判定は、オブジェクトの見た目と同じにする
- プレイヤーは上下左右に動かせる
- スコア、経過時間はタイトルに戻った際すべてリセットする
- 雑魚敵、敵の弾、プレイヤーの弾、アイテムともに画面端へ触れると消失する（この際、雑魚敵の消失は撃破でないため、得点にはならない）
- 敵の弾はプレイヤーに触れた場合も消失する
- プレイヤーの弾は雑魚敵やボスに触れた場合も消失する
- 弾は、上限に達している場合、既存の弾が消失するまで出現しない
- ボスは撃破するか、ゲームオーバーになるまで消失しない
- アイテムはプレイヤーに触れた場合、アイテムが消失し、プレイヤーに効果を与える
