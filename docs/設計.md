## 持っている情報
| オブジェクト | 持っている情報 |
| ------------ | -------------- |
| プレイヤー | 座標(x,y)、移動速度、残りHP、長押し時弾発射待ち時間、連打時弾発射待ち時間、被弾時のスコア減少量、弾の発射位置(x,y):プレイヤーの右端中心 |
| 雑魚敵 | 座標(x,y)、移動速度、残りHP、弾発射の待ち時間、撃破時のスコア増加量 |
| ボス | 座標(x,y)、移動速度、進行方向、行動パターン、プレイヤーの座標(x,y)、弾発射待ち時間、残りHP、撃破時のスコア増加量、出現中かどうか |
| プレイヤーの弾 | 座標(x,y)、移動速度、進行方向、ダメージ |
| 敵の弾 | 座標(x,y)、移動速度、進行方向、ダメージ、雑魚敵の左端中心の座標(x,y) |
| HUD | スコア、経過時間 |
| アイテム | 座標(x,y)、移動速度、|




## 移り変わりの条件

- タイトル -- Enterキー --> 武器選択
- 武器選択 -- Enterキー --> 選択した武器でプレイ中
- プレイ中 -- プレイヤーHPが0 --> ゲームオーバー
- プレイ中 -- 大ボスHPが0 --> クリア
- ゲームオーバー -- Enterキー --> タイトル
- クリア -- Enterキー --> タイトル

## 各仕様


#### 雑魚敵
- 雑魚敵AとBは右端から出現し、左へ動く
- 雑魚敵Cは、出現時プレイヤーへ正面を向け、画面端へ触れるまで直進する


#### 敵の弾
- 敵の弾は、雑魚敵の左端中心、ボス左端最上部、中心、最下部からも撃たれ、左へ動き続ける


#### プレイヤーの弾
- プレイヤーの弾は、プレイヤーの右端中心から撃たれ、右へ動き続ける
- プレイヤーは弾を放つ際、長押しなら一定間隔で弾を放つ
- 5f以上20f以内の間隔でスペースキーを連打した場合、スペースキーを押すたびに弾を発射する。最大5fごとに弾を発射できる


#### ボス（紫）
- ボスはゲーム開始後1200fに画面右端から出現し、左方向へ300ピクセルを1秒書けて移動する。
- 進み終わった時点でプレイヤーの弾が当たるようになり、攻撃を開始する。その後はx座標を固定する
- ボス出現時の雑魚敵や敵の弾は変わらず存在するが、出現後からは雑魚敵は出現しなくなる
- ボスは攻撃を開始してからはx座標は変化しないため、プレイヤーと接触することはない
- ボスには行動パターンが2種あり、ボスが300ピクセル移動してから一定時間毎にAとBを交互に切り替える。初めはパターンAから始まる。
- 行動パターンA : 常にy方向へ移動し、弾を発射する。画面端へ触れると切り返す。初めに動く方向はランダム。
- 行動パターンB : 常にプレイヤーのY座標を追尾し、プレイヤーのY座標に合わせて弾を発射する。
- ボスはHPが20以下になった瞬間、前半から後半へ切り替える
- ボスは前半と後半で弾発射の待ち時間と移動速度、発射する弾が変化する
- 前半、後半の切り替えと行動パターンの変化は別々で扱う
- 前半、後半、どちらでも行動パターンの切り替えは同じように起きる
- 後半のみ、前半の3発に加えそれぞれの弾の間からも弾を放ち、5発撃つようにする


####　アイテム
- アイテムは３つあって、雑魚敵を倒すと25％の確率でそれぞれ3つのアイテムがランダムで排出する
- アイテムはプレイヤーに触れると消えてプレイヤーに効果を与える
- アイテムは敵と同じ進行方向で流れてくるようにする


####　ストック式爆弾　(アイテム)
- ストック式爆弾は、3個までストックできるようにする
- ストック式爆弾は、ｚキーで使用できるようにする
- ストック式爆弾は、ボスに10ダメージ与える


####　スター状態　（アイテム）
- スター状態になるアイテムは180fの間無敵状態になり、無敵状態の時に敵、に触れると自分の体力を減らさずに、敵を倒してスコアをもらうようにする
- スター状態の時は体が0.5秒ごとに白く点灯するようにする
- 無敵状態中は1ダメージも受けないようにする


####　スコアポイント獲得量増加　（アイテム）
- スコアポイント獲得量増加のアイテムは300fの間スコアポイント獲得量を1.25倍にする状態になり、スコアポイント獲得量が増加する状態の時に敵を倒すと獲得するポイントが1.25倍になるようにする
